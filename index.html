Exhibit A Research and development

Vishing call detection

A system that identifies voice-phishing calls by examining spoken content and conversational patterns. It looks for signals such as urgency, false authority, requests for verification codes or payments, and pressure to keep the call secret. This tool was based on Swahili language and cultural context, and can be adapted to other languages.

Outcome: Verified accuracy was 85% on a test set of 200 calls. The system can be used to flag suspicious calls for further review, and to educate users about common vishing tactics. Link to the project code and dataset kept private. More than 1000 datasets were collected and used
